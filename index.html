Programming Fundamentals

ابدأ صح مع أساسيات البرمجة، المتغيرات، الشروط، الحلقات التكرارية، الدوال، وحل المشكلات باستخدام البرمجة.

SQL & Database Fundamentals

افهم تصميم قواعد البيانات، الجداول والعلاقات، وكتابة استعلامات SQL باستخدام أمثلة عملية.

Object-Oriented Programming (OOP)

افهم Classes وObjects وInheritance وEncapsulation وPolymorphism، وطبّقها في الكود.

Data Structures & Algorithms

Probability & Statistics

AI & Machine Learning

Computer Networks
